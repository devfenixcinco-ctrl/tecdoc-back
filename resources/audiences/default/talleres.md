# Talleres mecánicos

> Texto modelo para el prototipo. Fenix debe reemplazarlo por el contenido definitivo aprobado.

## Encuentre el repuesto correcto a la primera

Busque por marca, modelo y versión del vehículo, por número de artículo o por grupo de productos. {site} usa el catálogo TecDoc para mostrarle solo las piezas compatibles.

## Qué ofrecemos a los talleres

- Búsqueda de repuestos compatibles con cada vehículo.
- Cotizaciones de varios proveedores para la misma referencia.
- Menos devoluciones por piezas equivocadas.
